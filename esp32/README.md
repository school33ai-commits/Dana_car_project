# DANA-CAR — машинка ESP32 + телефон

Телефон следит за глазами водителя (сайт `v2/`) и по Bluetooth управляет машинкой:
глаза открыты — машинка едет вперёд, глаза закрыты дольше 2 с — она **медленно тормозит** до остановки.

## Порядок проверки

| Шаг | Скетч | Что проверяем |
|---|---|---|
| 1 | `test_motors/test_motors.ino` | каждый мотор крутится, и в какую сторону «вперёд» |
| 2 | `test_ble/test_ble.ino` + страница `v2/ble-test.html` | команды с телефона доходят до ESP32 |
| 3 | `dana_car/dana_car.ino` + сайт `v2/index.html` | всё вместе |

Arduino IDE: плата **ESP32 Dev Module** (пакет esp32 от Espressif, версия 2.0.14+ или 3.x).
Монитор порта — скорость **115200**.

## Пины моторов

| Мотор | Пин A (вперёд) | Пин B (назад) |
|---|---|---|
| 1 | P16 | P17 |
| 2 | P18 | P19 |
| 3 | P25 | P33 |
| 4 | P32 | **P35 ⚠** |

⚠ **P35 на ESP32 работает только на вход** (так же P34, P36, P39). Мотор 4 через него управляться не будет:
провод висит «в воздухе», и мотор может крутиться непредсказуемо.
Перекиньте этот провод на свободный выход — **P26, P27, P23, P13 или P14** —
и поменяйте `35` на новый номер в обоих скетчах (`test_motors` и `dana_car`).

## Тест моторов (шаг 1)

1. Поставьте машинку на коробку: колёса должны висеть в воздухе.
2. Залейте `test_motors`, откройте Монитор порта.
3. Скетч по очереди крутит каждый мотор ВПЕРЁД и НАЗАД, потом все вместе.
   Можно отправлять команды: `1`–`4` — один мотор, `f` — все вперёд, `b` — все назад, `s` — стоп, `a` — автотест.
4. Если колесо на «ВПЕРЁД» крутится назад — в `dana_car.ino` поставьте этому мотору `invert = true`.

## Тест Bluetooth (шаг 2)

1. Залейте `test_ble`, откройте Монитор порта.
2. На телефоне откройте `…/v2/ble-test.html`:
   **Android** — в Chrome, **iPhone** — в приложении **Bluefy** (Safari не умеет Bluetooth). Можно и с компьютера в Chrome.
3. «Подключить» → выберите **DANA-CAR**. Нажимайте кнопки — в Мониторе порта видно, что пришло.
4. «Тишина 5 с» — через 3 с ESP32 должен написать «ПУЛЬС ПРОПАЛ».

## Команды (одна буква)

| Команда | Когда | Машинка |
|---|---|---|
| `S` | наблюдение не запущено, калибровка | стоит |
| `0` | глаза открыты | плавно разгоняется и едет вперёд |
| `1`…`5` | глаза закрыты (уровень тревоги) | медленно тормозит до 0 за `BRAKE_MS` (3 с) |
| `N` | лица нет в кадре дольше 3 с | едет медленно |
| — | нет команд дольше 3 с | плавно останавливается |

Настройки скорости — в начале `dana_car.ino`: `CRUISE_SPEED`, `BRAKE_MS`, `ACCEL_MS`, `RESUME_AFTER_ALARM`.
